# 尝试补上：时间缩放规则 与 τ 可操作特征量

这是对《韬定律缺一个特征时间τ》的正面回应——尝试补上韬定律目前缺的两块：

1. **"τ 版的 Dennard"**：一条关于"时间如何缩放"的物理规则；
2. **"τ 版的 λ"**：一个可测量、可缩放的"特征时间"。

> 重要声明：以下是一份**思辨性草案**，基于物理直觉与量纲分析，**未经硅片验证**。
> 它更像一张"路线草图"，用来指明该往哪个方向补，而不是声称已经补完了。

---

## 一、先看清：Dennard 和 λ 各自"补"的是什么

- **Dennard（1974）补的是"规则"**：回答"等比缩小尺寸时，延迟、功耗、密度分别怎么变"，
  并给出一个**不变量**——功耗密度不变。有了不变量，缩放才可预测。
- **λ（1980）补的是"特征量"**：一个单一标量，把"设计"从"工艺"里解耦。换工艺 = 换 λ 值，
  设计不变。

所以"τ 版 Dennard"要找一条规则 + 一个不变量；"τ 版 λ"要找单一时间标量。

## 二、τ 版 Dennard：时间缩放的三条规则

### 规则 1：距离–延迟平方律（τ ∝ L²）

信号在导线上的 RC 传播延迟，其物理构成是：

```
R = ρL / (W·t)          （电阻正比于长度 L）
C = ε·W·L / d           （电容正比于长度 L）
τ = R·C = ρεL² / (t·d)   （延迟正比于长度平方 L²）
```

这就是**时间缩放的第一定律**：

> **τ ∝ L² —— 延迟对"距离"是平方依赖。**

它解释了韬定律最核心的技术选择：为什么是"折叠（缩短距离）"而不是"缩小晶体管"？
因为缩短距离对延迟的收益是**平方级**的，而缩小晶体管（缩短沟道长）对延迟的收益在速度饱和
后已退化为**线性**。这也是几何缩放在 7nm 后失效、而"3D 折叠"仍然有效的根本原因——
它攻击的正是几何缩放搞不定的"互连墙（interconnect wall）"。

### 规则 2：时间–能量耦合律（C ∝ L）

动态功耗的教科书公式：

```
P = α · C · V² · f
```

在先进节点，电容 C **由导线主导**（不是晶体管）。而导线电容 C ∝ L。于是：

> **缩短距离，同时压缩了延迟（τ∝L²）和电容（C∝L）。**

这就是何庭波论文②"通勤 vs 办公"比喻的物理本质：缩短导线 = 缩小 C = 降低功耗。
时间缩放和能量缩放是**天然耦合**的——这直接解释了"折叠后更密反而更凉"。

### 规则 3：能量–延迟积三次方律（EDP ∝ L³）——τ 缩放的不变量

Dennard 定律的不变量是"功耗密度不变"。τ 缩放的对应不变量，可以从**能量–延迟积**
（Energy-Delay Product, EDP = 能量 × 延迟）找到：

```
E   = C·V²          ∝ L·V²      （每周期能耗）
τ   = R·C           ∝ L²        （延迟）
EDP = E·τ = R·C²·V² ∝ L³·V²
```

在固定电压下：

> **EDP ∝ L³ —— 缩短距离 L → L/k，能量×延迟以 k³ 倍改善。**

这就是 τ 缩放的"免费午餐"：**压缩时间，连带压缩能量，而两者的乘积以三次方速度下降。**
它类比 Dennard 的"功耗密度不变"，给出了时间缩放"为什么值得做"的量化答案。

## 三、τ 版 λ：可操作特征量 τ₀

λ 之所以可操作，是因为它满足三个条件：单一、可测量、可缩放。τ 版的特征量也要满足这三条。

**定义 τ₀**：单位距离的信号延迟时间常数——即在给定工艺（导线电阻率 ρ、介电常数 ε、金属
间距）与键合间距下，**单位长度导线的 RC 延迟**：

```
τ₀ = ρε / (t·d)     （单位长度 L=1 时的 RC）
```

于是所有"时序"都能表示为 τ₀ 的整数倍，完全类比 λ 的 2λ、3λ：

| | λ（空间） | τ₀（时间） |
|---|---|---|
| 定义 | 最小特征尺寸 / 2 | 单位长度 RC 延迟 |
| 设计规则 | 线宽 2λ、间距 3λ | 关键路径预算 = n·τ₀ |
| 换工艺 | 换 λ 值 | 换 τ₀ 值 |
| "微缩" | 缩小 λ（缩小尺寸）| 缩小 τ₀（缩短距离 / 降 ρ、ε）|

这样，"时间缩放"就有了一个像"缩 λ"那样精确的含义：

> **缩 τ₀** = 缩短信号传输距离（3D 折叠）、降低导线电阻率（新材料）、降低介电常数（低 κ 介质）。

而 τ₀ 满足 λ 的三个条件：**单一**（一个标量）、**可测量**（每代工艺 + 键合间距下可测）、
**可缩放**（缩 τ₀ 有精确物理含义）。

## 四、用这套框架回看何庭波的数据

这份草案如果成立，应当能解释论文里那些"反常"的实测数据：

- **55% 密度提升 + 41% 功耗降低**：折叠缩短了关键路径距离 L，按规则 1（τ∝L²）延迟平方级
  改善 → 可在更低电压/频率下达到等性能；按规则 2（C∝L）电容线性下降 → 功耗直接降。
- **SRAM 频率 +40%**：位线/字线是 SRAM 的关键路径，折叠缩短它们，直接命中 τ∝L²。
- **时钟缓冲器 −50%、时钟布线 −28%**：时钟网络是最长的导线，是 τ∝L² 的最大受益者。
- **"更密反而更凉"**：按规则 3（EDP∝L³），缩短距离的三次方收益，压过了密度上升带来的功耗。

也就是说，这套草案不仅能"补上"，还能**反过来统一解释何庭波已经公布的数据**——这正是
一条好规则该有的样子。

## 五、诚实的声明：这只是草案

必须承认这份草案的局限，不能过度宣称：

1. **模型过于理想**：规则基于"单根导线"的 RC 模型，真实芯片有多层金属、多种延迟源
   （晶体管本征延迟、访存延迟、协议延迟），每一层的 τ 缩放规律未必都服从 τ∝L²。
2. **不变量未经验证**：EDP∝L³ 是量纲分析的结果，需要器件物理的严格推导 + 硅片实测。
3. **τ₀ 的定义有待细化**：ρ、ε、t、d 在真实工艺里不是常数，τ₀ 需要更精确定义。

所以严格说，这份草案回答的是"该往哪补"，而不是"已经补好了"。真正的"τ 版 Dennard"和
"τ 版 λ"，需要像 Dennard 1974 那样一篇严谨的论文——但本文至少证明了：**这个方向是通的，
不是死胡同。**

## 一句话总结

> 如果一定要给韬定律补上它缺的两块，可以这样补：
> **"τ 版 Dennard" = 距离–延迟平方律（τ∝L²）+ 时间–能量耦合律（C∝L）+ EDP 三次方不变量（EDP∝L³）；
> "τ 版 λ" = 单位长度延迟常数 τ₀，让"缩时间"像"缩 λ"一样可操作。**
>
> 这套草案能统一解释何庭波已公布的数据——但它仍是草案，离正式定律还差一次严谨的推导。
